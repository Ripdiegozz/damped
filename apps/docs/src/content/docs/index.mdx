<h2 id="packages">Three packages, one spring</h2>

The same analytic spring runs in the browser, in React and in React Native. Pick the layer you work at.

<div class="package-grid">
<PackageCard name="@damped/core" platform="Web" purpose="Animate elements, reorder with FLIP, morph one element into another and run springs on the compositor." href="/reference/core/">

```sh frame="none"
bun add @damped/core
npm install @damped/core
```

```ts frame="none"
import { animate } from "@damped/core";

const card = document.getElementById("card")!;
animate(card, { x: 240 }, { bounce: 0.15 });
```

</PackageCard>
<PackageCard name="@damped/react" platform="React 19" purpose="Hooks and a Presence component. Values reach the DOM without re-rendering on every frame." href="/reference/react/">

```sh frame="none"
bun add @damped/react @damped/core
npm install @damped/react @damped/core
```

```tsx frame="none"
import { useSpring } from "@damped/react";

export function Card({ open }: { open: boolean }) {
  const ref = useSpring<HTMLDivElement>({ scale: open ? 1.05 : 1 });
  return <div ref={ref}>Card</div>;
}
```

</PackageCard>
<PackageCard name="@damped/native" platform="React Native" purpose="withDamped, a withSpring replacement for Reanimated that keeps velocity on reversal." href="/reference/native/">

```sh frame="none"
bun add @damped/native
npm install @damped/native
```

```tsx frame="none"
import { withDamped } from "@damped/native";
import { useSharedValue } from "react-native-reanimated";

export function useToggle() {
  const x = useSharedValue(0);
  return () => {
    x.value = withDamped(x.value ? 0 : 200, { bounce: 0.15 });
  };
}
```

</PackageCard>

<h2 id="why">Why damped</h2>

<div class="why-grid">
<div class="why-point">
<h3>Interruptions keep their momentum</h3>
<p>Retarget a running animation, or reverse it halfway, and the new spring starts from where the element is, moving at the speed it had. Nothing snaps back to a standstill.</p>
<a href="/guides/interruption-and-reversal/">Interruption and reversal <span aria-hidden="true">&rarr;</span></a>
</div>
<div class="why-point">
<h3>Exact state at any time</h3>
<p>A spring is a closed-form function of time, not a per-frame integration. The same position and velocity come out at 60 Hz, at 144 Hz and on an irregular frame cadence, to within 1e-12.</p>
<a href="/guides/springs-explained/">Springs, explained <span aria-hidden="true">&rarr;</span></a>
</div>
<div class="why-point">
<h3>Smooth while the main thread is busy</h3>
<p>The optional compositor driver hands the browser a sampled keyframe animation. In Chromium, a 250 ms busy loop left the compositor box moving while the same spring on the main thread stood still.</p>
<a href="/guides/compositor/">The compositor driver <span aria-hidden="true">&rarr;</span></a>
</div>
<div class="why-point">
<h3>Reduced motion is respected</h3>
<p>Animations follow <code>prefers-reduced-motion</code> by default: movement jumps to its destination while fades and crossfades stay, so the interface still reads as changing.</p>
<a href="/guides/reduced-motion/">Reduced motion and accessibility <span aria-hidden="true">&rarr;</span></a>
</div>
</div>

<dl class="size-strip">
<div>
<dt>3.95 KB</dt>
<dd>gzipped, for an app that only calls <code>animate</code></dd>
</div>
<div>
<dt>6.97 KB</dt>
<dd>gzipped, for the whole of <code>@damped/core</code></dd>

</div>
</dl>
